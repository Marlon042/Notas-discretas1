

# Notas Discretas

Notas Discretas es una aplicación Android desarrollada en Flutter que permite gestionar y organizar notas de manera sencilla y eficiente. La app está diseñada para ofrecer una experiencia intuitiva a los usuarios, facilitando la creación, edición y eliminación de notas discretas, ideales para llevar registros rápidos, ideas o información importante. Es útil tanto para estudiantes como para profesionales que requieren anotar y consultar información en cualquier momento.
